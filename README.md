# FaceSwap Pro (اندروید)

اپ تعویض چهره که **کاملاً روی خود گوشی** اجرا می‌شود؛ هیچ عکسی به سرور فرستاده نمی‌شود.

## اجرا

1. نصب [Android Studio](https://developer.android.com/studio) (نسخه‌ی Koala یا جدیدتر) و JDK 17 (همراه Android Studio می‌آید).
2. پوشه‌ی `FaceSwapPro` را با **File > Open** باز کنید و صبر کنید Gradle همگام‌سازی شود.
   - در اولین build مدل `face_landmarker.task` (حدود ۴ مگابایت) خودکار از سرور Google دانلود و در `app/src/main/assets/` ذخیره می‌شود. اگر اینترنت build محدود است، فایل را دستی همان‌جا بگذارید:
     `https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task`
3. گوشی (Android 10 به بالا) را وصل کنید و Run بزنید. برای APK نهایی: **Build > Build APK(s)**.

## روش کار

1. **MediaPipe Face Landmarker** ۴۶۸ نقطه‌ی چهره را در هر دو عکس پیدا می‌کند.
2. روی نقاط عکس پایه مثلث‌بندی Delaunay انجام می‌شود و هر مثلثِ چهره‌ی جایگزین با تبدیل affine روی مثلث هم‌ایندکس خودش وارپ می‌شود.
3. رنگ و نور پوست در فضای LAB با عکس پایه تطبیق داده می‌شود.
4. با **Poisson seamless clone** (OpenCV) لبه‌ها بدون درز ترکیب می‌شوند.
5. اسلایدر «شدت اثر» نتیجه را با عکس اصلی ترکیب می‌کند.

## نکات برای نتیجه‌ی بهتر

- هر دو عکس واضح، با نور یکنواخت و چهره‌ی تقریباً روبه‌رو باشند.
- موی روی پیشانی، عینک و دست جلوی صورت باعث لکه‌ی ناخواسته می‌شود.
- اگر رنگ خروجی غیرطبیعی بود، «ترکیب بدون درز» را خاموش و روشن کنید و با اسلایدر شدت را کم کنید.

## محدودیت‌ها

روش مبتنی بر لندمارک برای چهره‌های روبه‌رو عالی است، ولی برای زاویه‌ی خیلی کج یا حالت‌های شدید (دهان باز، چشم بسته) به کیفیت مدل‌های عصبی نمی‌رسد. برای ارتقا می‌توان یک مدل swap عصبی (ONNX Runtime) اضافه کرد؛ مجوز مدل‌ها را حتماً بررسی کنید، چون بسیاری فقط برای استفاده‌ی غیرتجاری هستند.

## اخلاق و قانون

فقط از عکس‌هایی استفاده کنید که اجازه‌ی استفاده از آن‌ها را دارید و خروجی را به‌عنوان تصویر واقعی دیگران منتشر نکنید.
